The app will be an app will be an app that represents the base of a wargame.
the app should be made with plain javascript css and html.
the app will be deployed to github pages.
The app when opened should have a start menu with a start button, a select faction button, create faction button and create an army button.
The selected faction should be remembered
The selected faction will be the faction you use in game.
A faction contains multiple units and rules for those units.
A unit should have a stat line: health, defense, dodge, supply
Units can equip weapons. The same weapon can be equipped more than once.
A faction has weapons, created in the faction editor. Units can only equip weapons of their own faction.
A weapon has a name, hit value (X+ rolled on a d6, 2-6), attacks (a number or dice like D6, 2D6, D3+1), range (melee or a number), armour piercing (AP, 0 or more) and abilities.
Weapons are shown on a unit sorted by range, longest first and melee last.
Special abilities can be added to units which contain a textual description of the ability.
A faction can have shared abilities. Each shared ability targets units, weapons or buildings and can be ticked on any item of that kind, next to its own custom abilities.
Units will have a name.
A faction will have buildings.
Buildings have a special ability like units.
Buildings have a statline: generation(amount of points), cost, units, supply bonus
Supply is a resource. Every army has a starting supply (default 7) set in the army builder.
Units have a supply cost (default 1). Creating a unit uses its supply as well as 1 command point.
A unit costing more supply than you have left cannot be created. Slain units give their supply back.
Built buildings add their supply bonus to your total supply. Buildings never cost supply.
Create an army should bring you to a screen to create an army for a faction.
When creating a army you should gain an X amount of points set at the start.
buildings can be selected when creating a army.
the same building can only be picked 3 times at most.
buildings when selected add their units to your roster.
buildings can have a selection of units where you pick which units to bring with that building.
buildings could have no units.
buildings can have a special ability which would exhaust the building only use once per round.
when the game is started you should see your base and gain 3 command points.
a command point can be used to activate a unit, build a building or activate a building or create a unit form a building.
when a building is build is can be activated from then on.
A building can at most create 3 units.
units can die and should be selected that way to make the build unit action available again.
